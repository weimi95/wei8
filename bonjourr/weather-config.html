Wei8 天气源设置

Bonjourr 自带的天气服务端已失效（实测三个 provider 全部 503 / 返回空 body）， 本设置用于把天气请求改接到可直连的数据源。

1. 选择数据源

两点提醒：① 页面是公开的，Key 存在浏览器本地 localStorage 里，任何人都能在 F12 里看到， 请务必在控制台给凭据配置「应用限制」域名白名单，把可用域名限定为本站。 ② 和风从 2027-02-01 起会限制 API Key 的每日请求数，个人用量够用。

2. 连通性自测（在你当前网络下实测）

自测直接用浏览器发请求，走的就是你平时的网络线路 —— 哪个通就用哪个。

测试坐标固定为泉州（24.874, 118.576）。

3. 下一步

保存后回到 导航页，按 Ctrl + F5 强制刷新即可生效。 想排查问题可在控制台执行 localStorage.setItem('wei8-weather-debug','1') 打开日志， 天气请求的接管过程会打印在 Console 里。
